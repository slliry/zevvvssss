# 📹 Видео по языкам

Эта папка содержит видео для каждого языка сайта.

## 📁 Структура файлов

Добавь видео файлы с названиями по языковым кодам:

```
videos/
├── ru.mp4  - Русский
├── en.mp4  - English
├── kk.mp4  - Қазақша
├── uz.mp4  - O'zbek
├── ky.mp4  - Кыргызча
└── tr.mp4  - Türkçe
```

## 🎬 Требования к видео

- **Формат:** MP4 (H.264)
- **Рекомендуемое разрешение:** 1920x1080 (Full HD)
- **Соотношение сторон:** 16:9
- **Рекомендуемый битрейт:** 5-8 Mbps для HD

## 📤 Как добавить видео

### Локально:
1. Скопируй видео файл в эту папку
2. Переименуй его в соответствии с языком (например, `ru.mp4`)
3. Перезапусти сервер

### На продакшене (Docker):
```bash
# Скопируй видео на сервер
scp your-video.mp4 user@server:/path/to/project/backend/public/videos/ru.mp4

# Или через Docker
docker cp your-video.mp4 zeus-app:/app/public/videos/ru.mp4
```

## 🔄 Fallback

Если видео для конкретного языка не найдено, система автоматически покажет русское видео (`ru.mp4`).

## 🌐 API

Видео доступны через API:
- `GET /api/videos/:lang` - получить видео для языка
- `GET /api/videos` - список доступных видео

Примеры:
- `/api/videos/ru` - русское видео
- `/api/videos/en` - английское видео

## ✅ Проверка

Проверь доступные видео:
```bash
curl http://localhost:4000/api/videos
```

Ответ:
```json
{
  "supportedLanguages": ["ru", "en", "kk", "uz", "ky", "tr"],
  "availableVideos": ["ru", "en"],
  "message": "2 video(s) available"
}
```
